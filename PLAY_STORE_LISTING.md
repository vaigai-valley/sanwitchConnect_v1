## 📄 Full Description
*(Google Play Character Limit: **Up to 4,000 characters**)*

```text
Sanwitch Connect is the official mobile companion app for Sanwitch IDE. Seamlessly control physical microcontrollers (ESP32, ESP8266, RP2040), stream real-time sensor telemetry, build custom touch dashboards, and sync block-based MicroPython logic directly to your desktop IDE.

Whether you are prototyping smart home automation, tuning drone avionics, or testing robotics hardware, Sanwitch Connect bridges the gap between mobile touch interfaces and embedded hardware.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🌟 KEY FEATURES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📱 DYNAMIC IOT DASHBOARD & WIDGETS
• Add custom interactive controls in seconds: Toggle Switches, Numeric Sliders, Virtual Joysticks, RGB Color Pickers, Push Buttons, and Live Gauges.
• Reorder, customize, and configure widget command strings with an intuitive touch editor.
• Save and load custom layouts locally on your device.

📡 DUAL-MODE HARDWARE CONNECTIVITY
• Bluetooth Low Energy (BLE): High-speed, low-latency BLE UART communication with ESP32 microcontrollers.
• WiFi Direct & Local Network: Connect directly to on-chip web servers (e.g. 192.168.4.1) or local network endpoints.

🔄 INSTANT DESKTOP IDE PAIRING & PUSH
• Scan the QR code on your desktop Sanwitch IDE to establish an instant, secure session.
• "Push to IDE": Stream your mobile widget layout and generated MicroPython logic directly onto the desktop workspace with a single tap.
• Live bi-directional pairing status with real-time phone model detection.

📊 LIVE TELEMETRY & HARDWARE TWIN
• Monitor real-time analog and digital sensor streams with interactive graphs and numeric readouts.
• Zero-lag feedback for IMUs (MPU6050), environmental sensors (BME280), ADCs (ADS1115), and GPIO expanders (MCP23017).

🚀 STANDALONE APP EXPORT (PWA / WebAPK)
• Export your custom IoT dashboards as standalone native sub-apps directly on your phone.
• On-device cryptographic signing ensures clean, secure app installation.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• Raspberry Pi Pico W & RP2040
• Nordic Semiconductor BLE UART Protocol (Nordic UART Service)
• Standard HTTP REST / WebSocket Web Servers
```

# ⚡ Sanwitch Connect - Version 1.0 Mobile App

Sanwitch Connect Version 1 is a 100% offline, native-wrapped IoT controller app built for mobile devices.

## 🚀 Key Features

* **100% Offline Phone Storage PWA**: Export dynamic IoT control dashboards directly to local phone memory as `{appname}.html` files.
* **1-Tap PWA Launching**: Opens local Data URI in Chrome to trigger native "Add to Home Screen" PWA installation prompts.
* **Bottom-Left `^^^` Menu**: Integrated popup menu sheet with **📁 MY APPS** and **⚡ EXPORT APP**.
* **My Apps Local Manager**: Reopen, edit, run, and delete saved `{appname}.html` app layouts locally without server dependencies.
